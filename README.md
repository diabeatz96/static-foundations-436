# static-foundations-436
Project 1 for CSC 436.

This is the first project of 6 in my CSC 436 class, Hunterpedia. I wanted to make a basic Hunter x Hunter themed website for the subject. 

I've included the 5 main characters in the show, Gon, Killua, Kurapika, Leorio, and Hisoka. They each have two images, a description, and a fun fact about them! Each page also has its own theme matching the character.

You can run this website by forking and cloning this repository:
git clone {repo url}

Then, you can run a Live Server extension in your IDE.
